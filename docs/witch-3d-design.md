# Nyx 女巫 · 立体角色与动作设计 v2

用户确认方向：真实 3D 网格与模型，不再以人物图片承担角色；深紫星空、兜帽法袍、神秘但不恐怖。默认遮面，允许通过抬头、侧转看见眼睛与部分面部。保持全屏网页与固定 78 张牌。

## 造型决策

采用「蒙面守夜人」：修长成年女性比例，重心稳定地坐在桌后；深葡萄紫外袍、灰紫内衬、少量旧银滚边与月牙胸针。轮廓由真实兜帽厚度、肩披、上身、层叠裙摆及钟形袖口构成。面部不是黑洞，也不是发光眼贴图：有头颅、鼻梁、眼眶、眼球与虹膜的几何体；下半脸覆盖有曲面的不透明薄面纱。

三个候选路线的取舍：全遮脸雕像缺少目光交流；完整写实裸脸需要更多面部雕刻、皮肤贴图与表情制作，容易在初版出现违和；蒙面半露眼在保持神秘感的同时，让头部朝向和眼睛具备可读性，因此采用第三条路线。

模型默认略低头，兜帽边缘遮住上额。迎接时抬头约 8–12°；倾听时侧倾约 3–5°；思考时向桌面低头约 8°；与鼠标互动的头部跟随限制为左右约 12°、上下约 6°。眼睛可以先动，头部延迟跟随。不持续盯随鼠标，不突然露出完整面孔。

## 模型结构与材质

- 头与颈：立体头颅、鼻梁、眼球、虹膜、眼睑轮廓、眉部、耳侧轮廓；面纱独立建模，预留替换完整面部接口。
- 衣服：裙摆纵向褶皱、收腰内袍、肩披、厚兜帽与内衬、左右袖子、袖口内壁。布料通过模型几何形成褶皱，不能只画在平面上。
- 手：独立掌体、拇指与四指，带关节，避免用一块椭球充当整只手。抓牌将来需要按牌位驱动手腕目标。
- 首饰：银色月牙、领口与袖口滚边，控制细节密度；面部与手是阅读焦点。
- 网页材质：真实粗糙度、金属度、法线与灯光响应。外袍偏粗糙，内衬略柔亮；眼球少量反光，虹膜不做激光式发光。当前不宣称具备皮肤次表面散射、实时布料或影视级毛发。

骨架至少包含 Root、Spine、Chest、Neck、Head、左右 UpperArm / Forearm / Hand、手指关节。衣服与身体用蒙皮绑定，装饰绑定相应骨骼。动作以标准 GLB animation clips 输出，保留 Blender 源文件。源文件 Blender Z-up，导出 GLB Y-up；模型正面朝网页 +Z。

## 完整交互时序

| 阶段 / 触发 | 女巫动作与节拍 | 播放规则 | v2 范围 |
|---|---|---|---|
| 大门打开、进入占卜室 | 0–0.6 秒保持低头；0.6–1.6 秒缓慢抬头、转向来访者；1.6–2.8 秒右手轻抬示意，再落回桌边 | Greeting 单次，随后 Idle | 制作基础骨骼片段 |
| 无操作停留 | 胸肩轻微呼吸，手指缓慢放松，头部不规则地微转；完整循环约 6 秒 | Idle 循环；鼠标目光是限幅叠加，不转整个人物 | 制作 |
| 输入问题 | 微前倾与侧头，双手收拢，目光转向用户 | Listening 4 秒循环；输入结束后恢复 | 制作 |
| 等待解读结果 | 目光落向牌桌，头部小幅偏转，一手稍抬、短暂停顿再落下 | Thinking 4.8 秒循环，结果到达后平滑切换 | 制作；不是假装已经理解问题 |
| 洗牌过场 | 双前臂向中央聚拢，左右手交替轻抬，手指收曲 | Shuffle 与现有 1.5 秒洗牌过场对齐 | 制作手势；实体牌堆接触另留接口 |
| 用户浏览 78 张牌 | 双手舒展后回到桌边，轻低头关注牌桌，避免遮挡选牌区域 | Offer 约 2.4 秒循环 | 制作；不遮挡可点选牌 |
| 点击一张牌 | 0–0.15 秒准备；0.15–0.45 秒手腕引导；0.45–0.62 秒收回 | Drawing 单次，对齐现有抽牌飞行 620ms | 制作引导手势；未实现精准拾取接触 |
| 翻牌 | 0–0.2 秒抬腕；0.2–0.5 秒掌面转开；0.5–0.7 秒回到中性位 | Reveal 单次，对齐翻牌 700ms | 制作 |
| 展示解读 | 抬头面对用户，手掌缓缓打开，轻点头后收手 | Speaking 循环；不作无声口型表演 | 制作；真实语音音素驱动留接口 |
| 阅读图鉴 / 历史 | 减少手势，低头或轻侧转，安静等待 | Idle；面板不触发夸张表演 | 制作 |
| 抬头观察 / 不同视角 | 独立模型检查页可拖动旋转、查看前面/侧面/背面与线框，并选择动作 | 全屏检查工具，使用同一个 GLB | 制作，用于证明体积与动作 |
| 页面隐藏 / 减少动态 | 隐藏页面暂停更新；关闭动态时回归稳定姿势，不在复杂动作中随机冻住 | 遵从设置及系统偏好 | 接入 |

状态优先级：检查页手动动作 > 抽牌 / 翻牌短动作 > 洗牌 > 思考 > 说话 > 倾听 > 等待选牌 > 入场 > 待机。切换以 0.2–0.35 秒混合；不足一秒的动作使用更短混合以保留关键姿势。单次片段不无限循环。

## 接口与后续制作边界

运行时动作名：Idle / Greeting / Listening / Thinking / Shuffle / Offer / Drawing / Reveal / Speaking。每个片段必须在导出文件中实际存在，不能仅在配置中写名字就标记完成。

预留 `gazeTarget`（眼睛/头的世界坐标目标）、`handTarget`（牌位与左右手）、`visemes`（音素和时间戳）、`expression`（blink / focus / soften）、`clothQuality`、`faceVariant` 接口设计。v2 不实现手部 IK、真实牌堆物理、实时布料、音素口型或完整写实面部表情；不得把未实现配置展示成可用功能。

当前手指与手臂动画用于引导，DOM 卡牌仍保持原有身份和选择逻辑。后续精准抓牌需要将 DOM 牌位映射到 3D 桌面，并用 IK 和附着/释放事件同步，而不是靠手势猜位置。

## 验收方式

1. GLB 实际包含蒙皮与骨架、9 个命名片段；各片段有非恒定的骨骼关键帧。
2. 旋转到侧面和背面仍能看到兜帽、肩披、头部与身体体积，绝无人物图片平面替代。
3. 近看手部有分指，抬头可看到眼睛和鼻梁，面纱属于独立立体网格。
4. 网页使用同一个真实模型；提供待机、倾听、抽牌等动作的检查入口，保留原始模型供比较，不覆盖旧源文件。
5. 实际浏览器检查角色比例、手臂穿模、面部可读性、桌面遮挡和窄屏布局；报告已知精度差距，不能只靠导出成功声称美术完成。
